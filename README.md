# Airline App

An airline booking app starter with a React, TypeScript, and Vite frontend in
`airline-app-ui`, and an Express/TypeScript API in `server`.

## Requirements

- Node.js 20.19+ or 22.12+
- npm 10+

## Get started

```sh
npm install
npm run dev
```

The frontend is available at <http://localhost:5173> and the API at
<http://localhost:3101>. Vite proxies `/api` requests to the API server.

## Scripts

- `npm run dev` — run the frontend and API in development mode
- `npm run build` — build both workspaces
- `npm run typecheck` — type-check both workspaces
